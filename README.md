- 🤝 Возьму проект целиком: архитектура → разработка → деплой → поддержка в проде.

## Проекты

### 🤖 ZeonBot — экосистема бота для игры Puzzles & Survival

Веду **2+ года**. Это не «скрипт», а полноценная платформа на собственных серверах (self-host, VMware) с большой экосистемой сервисов.

- Микросервисы на **FastAPI / Python**, оркестрация в **Kubernetes**, хранилища **PostgreSQL / Redis / OpenSearch**, очереди **RabbitMQ**.
- **Computer Vision:** распознавание игровых экранов через **YOLO (Ultralytics)** и OCR (**PaddleOCR / Tesseract**).
- **MLOps:** инференс моделей на **NVIDIA Triton** с пробросом GPU внутрь VMware-контура.

### 🛡 AirShadow VPN — VPN-сервис под ключ

Распределённый VPN-сервис с сайтом, личным кабинетом, Telegram-ботом и приёмом платежей. Инфраструктура, бэкенд и лендинг — моя работа.

- **Каскадная сеть:** 3 точки входа в РФ и 4 точки выхода за рубежом.
- **Современные протоколы:** VLESS + Reality, VLESS + XHTTP. Клиенты под iOS / Android / Windows / macOS.
- Биллинг и подписки на базе **Remnawave**, всё живёт в проде с реальной регистрацией и оплатой.
